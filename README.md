# CODSOFT Java Development Internship

This repository contains the Java projects completed as part of my
CODSOFT Java Development Internship.

## Tasks Completed

### Task 1 - Number Game

A number guessing game where the computer generates a random number
between 1 and 100.

Features:
- Random number generation
- User guesses
- Higher/lower hints
- Limited attempts
- Multiple rounds
- Score calculation

### Task 2 - Student Grade Calculator

A Java program that calculates a student's total marks, average
percentage, and grade.

Features:
- Student name input
- Multiple subject marks
- Total marks calculation
- Average percentage
- Grade calculation
- Input validation

### Task 4 - Quiz Application

A multiple-choice quiz application with a time limit for each question.

Features:
- Multiple-choice questions
- 30-second timer
- Answer validation
- Score calculation
- Percentage calculation
- Final performance result

## Technologies Used

- Java
- Java Scanner
- Java Random
- Java Timer
- Object-Oriented Programming concepts

Compile the required Java file:
